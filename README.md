## 🔬 Core Technical Architecture

| Component | Technology | Technical Purpose |
| :--- | :--- | :--- |
| **Collision Generator** | `Gemini 2.0/3.5 Flash` | Discovers hidden tension between everyday habits and human cognitive biases. |
| **Storyboard Parser** | `Gemini API + JSON Schema` | Segments scripts into sentence-by-sentence dense micro-scenes (`MIN_SCENES = 10`). |
| **Regex Sanitizer** | `Python re module` | Negative prompt filtering stripping camera motion verbs (`montage`, `pull-away`) & CGI forcefields. |
| **Contextual Anchor** | `Dynamic Prompt Injection` | Dynamically attaches reference image anchors when observer character is present in scene. |
| **Speech Synthesizer** | `Supertonic Local Engine` | Synthesizes uncompressed 16-bit 0.90x WAV voiceover audio via HTTP endpoint. |
| **Studio Dashboard** | `Flask + HTML5 / CSS3` | Local web application for batch queueing, idea discovery, and asset preview. |

## 🎨 The 7 Golden Rules of Observer Cinematography

> [!TIP]
> All prompts generated by the studio adhere strictly to these locked channel cinematography rules:

```text
1. 👁️ OBSERVER PERSPECTIVE ──► Frame secondary subjects through the recurring observer's gaze.
2. 🖼️ STATIC FRAMING         ──► Describe still compositions; strictly forbid video motion terms.
3. 🌿 GROUNDED REALISM      ──► Replace sci-fi forcefields with physical distance & light.
4. 🎥 NO FILM JARGON        ──► Describe the picture itself, not camera equipment.
5. 🖤 EMOTIONAL INTENSITY   ──► Include one psychological mood sentence per scene.
6. 🛡️ QUALITY SHIELD        ──► Global negative prompt preventing horror/surreal distortions.
7. 🔄 VISUAL RHYTHM         ──► Dynamic progression across Close-up ➔ Wide ➔ Over-the-Shoulder.
```

## 🚀 Quick Start Guide

### 1️⃣ Clone & Install Dependencies

```bash
git clone git@github.com:rohitpadile/Youtube_Automation_Using_AI_101.git
cd Youtube_Automation
pip install -r requirements.txt
```

### 2️⃣ Environment Configuration

Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
SUPERTONIC_URL=http://127.0.0.1:7788/v1/audio/speech
```

### 3️⃣ Run Pipeline via CLI

```bash
# Generate complete video asset package for a collision pair
python generate_studio.py --concept-a "Earphones with No Audio" --concept-b "Social Armor"

# Brainstorm 20 fresh collision ideas live
python generate_studio.py --ideas
```

### 4️⃣ Launch Studio Web Dashboard

```bash
python app.py
```
Open `http://127.0.0.1:5000` to manage queues and trigger batch generation visually.
